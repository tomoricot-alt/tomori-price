# TOMORI PRICE｜AI買い物価格比較アプリ

> 「撮るだけ、話すだけ。いつもの買い物をもっと賢く。」

TOMORI PRICEは、スーパーやドラッグストアで商品の写真を撮影し、音声で店舗名を登録することで、複数店舗の商品の価格を比較できる個人向けAI買い物支援PWAアプリです。

最大の特長は、販売価格だけでなく**内容量を考慮した真の単価（100gあたり／100mlあたり／1個あたり）をプログラムで厳密に自動計算**し、どの店舗が一番お得かを可視化することです。

---

## 🌟 主な機能

### 1. 写真撮影＆商品棚の一括AI解析
- スマートフォンのカメラ直起動（`capture="environment"`）およびアルバムからの写真選択
- 画像の長辺1200px自動リサイズ＆JPEG圧縮によるIndexedDBの軽量化
- スーパーの棚写真に複数商品が写っていても、独立した商品候補として一括抽出
- Google Gemini API による商品名・ブランド・カテゴリー・内容量・単位・価格・値札テキストの自動認識
- 読み取り結果は必ず保存前にユーザーが確認・修正できる安心設計
- APIキー未設定でも体験できる「棚写真サンプル（オリーブオイル・パスタ）」プリセット搭載

### 2. 店舗名・価格の音声入力（Web Speech API）
- 「今日はスーパーAです。オリーブオイルが798円でした」と話すだけで、店舗名・商品名・価格を自動抽出
- マイク権限拒否時や非対応ブラウザ時の手入力フォールバック
- 音声データのプライバシー説明ダイアログ

### 3. 正確な単価自動計算
- 税込価格を基準とした基準単価の自動計算（100gあたり / 100mlあたり / 1個あたり）
- 税抜価格の場合は端数四捨五入（8%軽減税率または10%標準税率）で税込価格を算出
- **厳守ルール**: 重量（g, kg）と容量（ml, L）を無条件に換算せず厳密に分離管理

### 4. 店舗別価格比較＆最安値ハイライト
- 「類似商品で比較（おすすめ）」と「同一ブランド・商品で比較」の切り替えタブ
- 最安値店舗クラウンバッジ表示
- 価格差（例: 「スーパーBより 100gあたり ¥12.6 お得！」）の可視化
- 記録日表示および店頭価格保証外の免責事項明示

### 5. スマート買い物リスト
- 買うものの数量管理と購入済みチェック
- 登録された価格データベースから**最安値店舗を自動提案**
- 店舗ごとのまとめ表示・削除確認モーダル

### 6. バックアップ・データ保護
- ブラウザ内IndexedDB（`idb`）による完全ローカル保存
- JSONバックアップのダウンロード＆復元（重複データの自動スキップ・上書き防止）
- Excel / Google スプレッドシート互換の CSVエクスポート（BOM付きUTF-8）
- 指示書テストデータ（オリーブオイル2種・パスタ2種）の初期投入機能

## 🛠 技術スタック

- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Tailwind CSS (TOMORIブランドカラー設計)
- **データストレージ**: IndexedDB (idb)
- **PWA**: vite-plugin-pwa (Service Worker によるオフラインキャッシュ・ホーム画面追加)
- **アイコン**: Lucide React
- **AI画像認識**: Google Gemini API (gemini-1.5-flash / gemini-2.5-flash)
- **サーバーレスAPI**: Cloudflare Pages Functions (`/api/analyze-image`)
- **ホスティング**: Cloudflare Pages

## 📱 iPhone（Safari）でのご利用方法

1. SafariでCloudflare Pagesの公開URLにアクセスします。
2. 画面下部の中央にある「共有ボタン（四角から矢印が上に出ているアイコン）」をタップします。
3. メニューから「**ホーム画面に追加**」を選択します。
4. ホーム画面に「TOMORI PRICE」のアプリアイコンが追加され、ネイティブアプリ感覚でフルスクリーン起動できます。
5. カメラ撮影や音声入力のマイク使用許可ダイアログが出た場合は「許可」を選択してください。

## 🔒 セキュリティと費用ルール

- **完全無料枠運用**: 新規有料契約や課金は一切不要です。
- **APIキー非露出**: APIキーはGitHubリポジトリやフロントエンドソースコードにコミットされません。個人の無料APIキーを使用する場合はお使いの端末ブラウザ内（IndexedDB）に暗号化保存されます。
- **プライバシー保護**: 写真データはユーザーの明示的な同意なしに第三者へ送信・公開されません。
